# v2 설계 2 — 화면

> 상태: 초안 (2026-10-15) · 브랜치 `v2` · 데이터는 [01-데이터-동기화-설계](01-데이터-동기화-설계.md)
> 범위: PC(위젯 · 메인 창)와 휴대폰 첫 버전의 화면 구성, 공통 디자인 규칙, 테마 구조.
> 그림은 구조만 보여 주는 와이어프레임 — 실제 모양은 시안(4장 끝)에서 정함.

## 1. 원칙

1. **오늘에 집중** — 처음 보이는 건 언제나 "오늘 할 일과 오늘 일정". 나머지는 한 번 더 들어가서.
2. **입력은 한 줄** — `13:30 회의`, `마감 10/20 제출`, `KAMP > 모델링` 처럼 입력창 하나로 대부분을 (v1 그대로).
3. **복잡함은 꺼내 쓰게** — 기능이 많아도 꺼 둔 기능은 메뉴 · 화면에서 사라짐 (v1 의 '기능 켜고 끄기').
4. **무엇이든 되돌릴 수 있게** — 확인 창 대신 실행 후 "되돌리기" (v1 그대로).
5. **PC 와 휴대폰이 같은 느낌** — 같은 색 · 글꼴 · 아이콘 · 단어. 휴대폰은 PC 의 일부를 손에 맞게.

### v1 에서 고칠 점
- 창이 너무 많음 (일정표 · 기록장 · 통계 · 만다라트 · 대화상자 10여 개) → **메인 창 하나 + 왼쪽 메뉴**로 모음.
  위젯은 그대로 두고, 위젯에서 메인 창의 해당 화면을 엶.
- 대화상자 대신 **오른쪽 상세 패널** (목록을 보면서 고침).
- 고배율 화면 · 글자 크기 대응을 처음부터 (v1 은 픽셀 보정을 일일이 했음).

## 2. 화면 지도

```
PC
├─ 위젯 (바탕화면 고정 / 항상 위)          ← 늘 떠 있는 작은 창, 오늘만
└─ 메인 창 (필요할 때 여는 큰 창)
    ├─ 오늘          할 일 · 타이머 · 일정 · 마감 · 오늘의 기록 (위젯의 큰 버전)
    ├─ 일정표        주 · 2주 · 달 · 일정과 마감 추가/수정
    ├─ 기록장        다이어리(글 · 타임라인) · 데이트 일기   (+ 나중에 버킷리스트 등)
    ├─ 통계          시간 / 완료 기준, 기분 · 습관
    ├─ 목표          큰 목표 · 만다라트 · 습관 관리          (P3)
    └─ 설정          테마 · 기능 켜고 끄기 · 단축키 · 데이터(클라우드 연결 · 백업) · 정보

휴대폰 (첫 버전)
├─ 오늘          할 일 체크 + 오늘 일정 · 다가오는 마감
├─ 일정          주 · 달 보기, 일정 · 마감 추가/수정
├─ 데이트        데이트 일기 목록 · 쓰기 · 사진
└─ (설정)        클라우드 연결, 테마
```

## 3. PC — 위젯

```
┌───────────────────────────────┐
│ ❦ Daily Todo          ◆ ▢ ✕   │  ← 끌어서 이동 · 고정 방식 · 메인 창 · 닫기
│ ‹  10월 15일 목요일  ›   오늘   │  ← 날짜 누르면 달력
│ [일정 2 · 14:00] [마감 D-2] [목표]│  ← 접힌 칩: 핵심만, 누르면 펼침
│ ┌ 13:30 삐약이들 회의    2시간 후 ┐ │
│ └ 18:00 KAMP 회의              ┘ │
│ ┌───────────────────────┐ [+] │  ← 입력 한 줄 (할 일 / 일정 / 마감 / 기록)
│ ▬▬▬▬▬▬▬▬▬▬░░░░░░░             │  ← 오늘 진행률
│ ▾ ○ KAMP 경진대회     1:25:00   │  ← 묶음: 하위 합계
│     ● 모델링   ▶ 0:25:10  [정지] │  ← 진행 중 (햇살색)
│     ○ 발표 자료         [시작]  │
│   ○ 이메일 답장          [시작]  │
│   ✓ 운동 30분     0:30:00       │
│ ─────────────────────────────  │
│ ▾ 오늘의 기록   😐 기분 ○○○○○     │  ← 접기 가능
│ [운동 ✓3일] [독서] [+]           │  ← 습관 칩
│ ┌ 14:20 ✓ 모델링 완료 · 1:25 ┐    │  ← 타임라인 미리보기 (최근 3개)
│ └ 15:02 점심 맛있었다       ┘    │
│ 완료 2/5 · 총 2:10  [정리하기][통계]│
└───────────────────────────────┘
```
- v1 과 같은 동작: 바탕화면 고정 / 항상 위, 끌어서 이동 · 크기 조절, 두 PC 동시 사용 안내, 전역 단축키.
- **입력 한 줄의 종류**: 기본은 할 일. 글자로 구분 — `13:30 …` 일정, `마감 10/20 …` 마감, `KAMP > …` 하위 할 일,
  **`- …` 은 타임라인 기록** (새로). 입력창 왼쪽에 지금 무엇으로 들어갈지 작은 표시(할 일 · 일정 · 마감 · 기록).
- 오늘의 기록 칸은 v1 의 "일기 4줄" 대신 **타임라인 미리보기** → 길게 쓰려면 메인 창 기록장으로.

## 4. PC — 메인 창

```
┌──────────┬─────────────────────────────────────┬────────────────────┐
│ ❦ Daily  │  (가운데: 목록 · 달력 · 피드)              │ (오른쪽: 상세 패널) │
│          │                                     │  고른 항목을 바로 고침 │
│ ● 오늘    │                                     │  닫으면 가운데가 넓어짐 │
│   일정표  │                                     │                    │
│   기록장  │                                     │                    │
│   통계    │                                     │                    │
│   목표    │                                     │                    │
│ ─────    │                                     │                    │
│   설정    │                                     │                    │
│ 동기화 ✓  │  ← 마지막 동기화 시각 · 문제 있으면 노란 점        │                    │
└──────────┴─────────────────────────────────────┴────────────────────┘
```
- **3단 구조**: 왼쪽 메뉴 · 가운데 목록 · 오른쪽 상세. 창이 좁으면 상세는 덮는 패널로, 더 좁으면 메뉴는 아이콘만.
- 위젯의 링크(일정표 › · 기록장 › · 통계)는 메인 창의 그 화면을 엶.
- **명령 팔레트 (Ctrl+K)**: "일정표", "데이트 일기 쓰기", "테마 바꾸기" 처럼 이름으로 이동 · 실행.

### 4.1 오늘
위젯과 같은 내용을 넓게: 왼쪽 할 일 목록, 오른쪽에 오늘 일정 타임라인 · 마감 · 오늘의 기록.
할 일을 누르면 상세 패널(메모 · 예상 시간 · 측정 기록(세션 목록, 고치기) · 묶음 · 마감 연결).

### 4.2 일정표
v1 일정표와 같음 (이번 주 · 2주 · 달, 일정 | 마감 추가, 누르면 상세). 달 보기에서 칸을 끌어 날짜 옮기기 (새로).

### 4.3 기록장
```
┌ 기록장 ───────────────────────────────────────────────────────────────┐
│ [다이어리] [데이트 일기]            (나중에: 버킷리스트 · 가고 싶은 곳 …)        │
├──────────────┬──────────────────────────────────────────────────────┤
│ 10월 · 12편    │  10월 15일 목요일              [글 | 타임라인]    😊 좋음  │
│ 검색 ______    │  할 일 3/5 완료 · 2시간 10분 · 습관 운동                    │
│ ▸ 15 목 😊 KAMP…│ ─────────────────────────────────────────────────── │
│   14 수 😐 비가…│  09:10  ☀ 일어남 · "오늘은 일찍"                          │
│   13 화 —      │  10:00  ▶ 모델링 시작                                   │
│   …            │  11:25  ✓ 모델링 완료 · 1시간 25분          (자동)        │
│                │  13:30  📅 삐약이들 회의                    (자동)        │
│                │  15:02  점심 맛있었다  [사진 1]                            │
│                │  ┌──────────────────────────────────────┐  │
│                │  │ - 지금 남기기…                     [사진] [기분] │  │
└──────────────┴──────────────────────────────────────────────────────┘
```
- **다이어리 = 글 + 타임라인** 한 날짜 안에서 전환. 글은 넓은 편집 칸(v1 처럼), 타임라인은 피드.
- **자동으로 끼는 항목** (설정에서 종류별로 켜고 끔): 완료한 할 일 · 타이머 세션 · 일정 · 기분 변경.
  자동 항목은 흐리게, 직접 쓴 기록은 진하게.
- **데이트 일기**: 왼쪽 목록(날짜 · 제목 · 장소 · 별점 · 대표 사진 썸네일), 오른쪽 상세(사진 여러 장 갤러리,
  장소 · 별점 · 쓴 돈 · 이야기 · 태그). v1 칸 그대로 + 사진 여러 장.

### 4.4 통계
v1 주간 통계 + **기간 선택**(주 · 달 · 연) + 시간/완료 기준. 그래프는 SVG(선명, 테마 색 따라감).

### 4.5 설정
| 묶음 | 내용 |
|---|---|
| 모양 | 테마, 글꼴, 글자 크기, 간격(촘촘/보통/여유), 위젯 투명도 |
| 기능 | 기능 켜고 끄기 (v1 목록 + 타임라인 자동 항목) |
| 입력 · 단축키 | 전역 단축키, 입력 문법 안내 |
| 알림 | 일정 n분 전, 하루 정리, 장시간 타이머, 자리 비움 |
| 데이터 | 클라우드 연결(OneDrive · Google Drive), 동기화 상태 · 기기 목록, 백업 · 내보내기, 암호화, v1 가져오기 |
| 정보 | 버전, 업데이트, 단축키 표 |

## 5. 휴대폰 — 첫 버전

```
┌─────────────────────┐   ┌─────────────────────┐   ┌─────────────────────┐
│ 10월 15일 목      ⚙ │   │ ‹ 10월 ›   주 | 달    │   │ 데이트 일기        ＋ │
│ ┌ D-2 KAMP 제출   ┐ │   │ 일 월 화 수 목 금 토   │   │ ┌─────────────────┐ │
│ └ 13:30 삐약이들 회의┘ │   │ ·  ·  ●  ·  ◆  ·  · │   │ │ [사진]  10.15     │ │
│                     │   │ ─────────────────── │   │ │ 100일 기념 데이트  │ │
│ ▾ KAMP 경진대회 1/3  │   │ 15 목                │   │ │ 서울숲 · ★★★★★    │ │
│    ○ 모델링          │   │  13:30 삐약이들 회의   │   │ └─────────────────┘ │
│    ○ 발표 자료       │   │  18:00 KAMP 회의      │   │ ┌─────────────────┐ │
│ ○ 이메일 답장        │   │ 17 토                │   │ │ [사진]  10.09     │ │
│ ✓ 운동 30분          │   │  ◆ 마감 KAMP 제출     │   │ │ 한강 피크닉 …      │ │
│                  ＋ │   │                  ＋ │   │                     │
├──────┬──────┬───────┤   ├──────┬──────┬───────┤   ├──────┬──────┬───────┤
│ 오늘  │ 일정  │ 데이트  │   │ 오늘  │ 일정  │ 데이트  │   │ 오늘  │ 일정  │ 데이트  │
└──────┴──────┴───────┘   └──────┴──────┴───────┘   └──────┴──────┴───────┘
```
- **아래 탭 3개**: 오늘 · 일정 · 데이트. 설정은 오른쪽 위 톱니.
- **오늘**: 위에 오늘 일정과 3일 안의 마감, 아래 할 일. 동그라미를 누르면 체크(살짝 진동), 길게 누르면 수정.
  ＋ 는 PC 와 같은 한 줄 입력 (`13:30 …`, `마감 …` 도 그대로).
- **일정**: 주/달 전환, 날짜를 누르면 그날 목록, ＋ 로 일정 · 마감 추가, 누르면 수정 시트(아래에서 올라오는 패널).
- **데이트**: 카드 목록(대표 사진 크게), ＋ 로 새 기록 → 사진 고르기/찍기가 먼저, 그다음 제목 · 장소 · 별점 · 이야기.
- 휴대폰에 없는 기능(타이머 · 기분 · 통계 …)은 숨김. 데이터는 다 동기화되므로 PC 에서 그대로 보임.
- 동기화: 앱을 열 때 · 당겨서 새로고침 · 저장 직후. 오프라인이면 위에 "오프라인 · 연결되면 맞춰요".

## 6. 디자인 시스템

### 6.1 토큰 (CSS 변수 — 테마는 이 값들만 바꿈)
| 역할 | 예 (미니멀 테마) | 쓰임 |
|---|---|---|
| `--bg` / `--surface` / `--surface-2` | 미색 회백 `#f6f6f3` / 흰색 / 연회색 | 바탕 · 카드 · 바 |
| `--text` / `--muted` / `--faint` | 먹색 / 회색 / 옅은 회색 | 글자 3단계 |
| `--accent` / `--on-accent` | 짙은 숲 초록 `#2f6a4c` / 흰색 | 주요 버튼 · 완료 |
| `--active` / `--on-active` | 햇살 앰버 `#e9a23b` / 진한 갈색 | 진행 중 타이머 |
| `--danger` / `--danger-bg` | 붉은 주황 / 연분홍 | 삭제 · 마감 임박 |
| `--border` / `--focus` | 연회색 / 숲 초록 | 테두리 · 키보드 포커스 |

- 간격 4px 단위, 모서리 둥글기 3단계(6 · 10 · 16px), 그림자 2단계, 움직임 120~200ms ("움직임 줄이기" 설정 존중).
- 글자 크기 단계: 12 · 13 · 15(기본) · 18 · 22 · 28.

### 6.2 테마
| 테마 | 느낌 |
|---|---|
| **미니멀** (기본) | 흰 바탕 · 회색 · 포인트는 숲 초록 한 색 + 진행 중 앰버 |
| 숲 우드 | v1 의 베이지 + 진한 초록 + 햇살 앰버 |
| 다크 숲 | 짙은 침엽수 초록 바탕 + 이끼색 (v1 첫 디자인) |
| 파스텔 | 연한 분홍 · 하늘 · 민트 |
| 고대비 | 접근성: 대비 7:1 이상 |
- 사용자가 포인트 색만 바꾸는 것도 허용 (나머지는 테마가 맞춰 계산).
- **글꼴**: 기본 Pretendard(무료 · 한글 가독성), 다이어리용 명조(마루 부리), 손글씨 느낌 글꼴 1~2종.

### 6.3 컴포넌트
- 접근성 기본기가 갖춰진 Radix UI 의 동작만 쓰고 모양은 직접 (테마 자유도).
- 공용: 버튼 · 칩 · 체크 동그라미 · 입력 한 줄 · 상세 패널 · 바텀 시트(휴대폰) · 토스트 · 되돌리기 줄 ·
  달력 · 별점 · 기분 얼굴 · 사진 갤러리 · 빈 화면 안내.

## 7. 상호작용 규칙 (v1 에서 가져옴 + 정리)

| 상황 | 동작 |
|---|---|
| 지우기 | 바로 지우고 아래 "되돌리기" 6초 · Ctrl+Z |
| 순서 | 길게 누르거나 끌어서, 같은 높이끼리 (묶음은 통째로) |
| 타이머 | 하나만 켜기(기본), 자리 비움 · 절전 · 자정 처리, 두 기기 동시에 켜면 안내 |
| 알림 | OS 기본 알림 (Windows 알림 센터 · 휴대폰 알림) |
| 키보드 | 위젯 불러오기 · 타이머 · 정리하기 전역 단축키, Ctrl+K 명령 팔레트, 모든 버튼 Tab 이동 |
| 빈 화면 | 무엇을 할 수 있는지 한 줄 + 입력 예시 |

## 8. 접근성
- 글자 대비 4.5:1 이상(고대비 테마 7:1), 글자 크기 설정이 화면 전체에 적용, 키보드만으로 모든 기능,
  화면 읽기 프로그램용 이름(체크 동그라미 = "모델링, 완료 안 함").

## 9. P2(데스크톱 셸)에서 만들 범위 — 1차 구현 (2026-10-16, [apps/desktop](../../apps/desktop))
- 위젯 + 메인 창 틀(왼쪽 메뉴 · 상세 패널) + **오늘** 화면
- 할 일 · 묶음 · 드래그 정렬 · 되돌리기 · 타이머(세션) · 입력 한 줄(할 일 · 하위)
- 클라우드 폴더 동기화 · v1 가져오기 · 테마 2개(미니멀 · 다크 숲)
- 나머지(일정표 · 기록장 · 통계 · 목표 · 휴대폰)는 P3 · P4
- 1차 구현: 위 범위 + 입력 한 줄의 일정 · 마감 · 기록(`- …`)까지. 위젯과 메인 창은 창마다 복제본을 따로 두고
  (기록 파일도 따로) 쓰면 서로 알려 즉시 맞춤. 세션은 PC ID 로 적어 두 창이 한 기기로 보임.
  기기 안 저장은 우선 JSON 파일(`local-<창>.json`), SQLite 는 데이터가 커지면.
- P2 에 남은 것: 전역 단축키 · 자리 비움/절전/자정 처리 · 날짜 달력 팝업 · Ctrl+K · 일정 알림 → P3 와 함께
